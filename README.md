## Building

| **[Axon](https://github.com/harshkedia177/axon)** | Graph-powered code intelligence. Indexes any codebase into a knowledge graph and serves it over MCP so agents query the graph instead of re-reading files. 700+ stars. `pip install axoniq` |

## Where I've shipped

- **Shoppin** : owned the systems behind an AI fashion product as it grew from discovery and try-on into full commerce and custom manufacturing. An agent-based pattern-making engine (garment to production-ready ASTM sewing pattern in minutes), an AI-native custom-clothing platform, the recommendation feed, the entire payments stack, and virtual try-on for 20K+ daily users.
- **Verbaflo.AI** : built the whole backend for a multi-modal agentic platform on FastAPI, scaled to 20K+ concurrent sessions, a hybrid RAG pipeline on Milvus, and multi-provider LLM infrastructure over gRPC that became the standard across every team.
- **Sidecar** : a 24/7 autonomous freight-forwarding agent, end to end. Email intake, structured extraction over messy docs, and an agentic quoting loop with no human in the loop. Hours to minutes, 3x outbound volume.
- **PrudentBit** : secure file-sharing on Azure (SAML SSO, 2FA, DLP, malware scanning) for Toyota and UCO Bank. Rewrote the backend across 130+ APIs, cutting latency from 1s to 30ms.
- **Convin.AI** : real-time CDC pipelines (Debezium and Kafka into Apache Pinot, in Go) for contact-center analytics.
